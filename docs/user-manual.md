## 1. 快速开始

```
前提：安装了 .NET 8 SDK，Windows 系统。

打开终端 → 进入项目目录 → 运行:

  dotnet run --project src/DataProbe.Api

打开浏览器 → 访问 http://localhost:18801

你看到的就是这个东西——一个输入框加一个按钮。
在输入框里打上你想看的目标，按「开始调查」。
```

**不需要管理员权限就可以开始的场景：**

```
浏览器访问的网站（如 example.com）
  → 输入域名或 URL
  → 按开始
  → DataProbe 自动设置系统代理
  → 打开浏览器访问目标
  → 看结果

微信小程序（PC 端）
  → 输入小程序相关的域名
  → 按开始
  → 打开微信小程序
  → 看数据
```

## 2. 安装说明

### 2.1 基础安装（必须）

```bash
# 1. 确保已安装 .NET 8 SDK
dotnet --version
# 应该输出 8.0.x

# 2. 进入项目目录
cd d:/sjmm/code/data-probe

# 3. 编译
dotnet build

# 4. 启动
dotnet run --project src/DataProbe.Api
```

### 2.2 可选依赖安装（按需）

这些不是必需的。不装也能用，装了就多几个能力。

```
安装 Frida（绕过证书锁定需要）:
  pip install frida-tools
  → 装完后 ProcessHook 通道自动启用

安装 ddddocr（本地验证码识别需要）:
  pip install ddddocr
  → 装完后 CAPTCHA OCR 求解器自动启用

安装 WinTUN 驱动（L3 全流量捕获需要严重）:
  WinTUN 驱动已随项目部署在 deps/ 目录
  Tunnel 通道需要管理员权限才能使用

配置 2Captcha（远程验证码求解需要）:
  在 config.json 中设置 2Captcha API Key
  → 装完后 reCAPTCHA/hCaptcha 自动走远程求解
```

> 所有外部依赖都可拆卸。**不装不影响核心功能。** 装了某个依赖但用不了？对应功能自动降级跳过。

### 3.1 完整流程（5 分钟）

```
第 1 步: 打开 http://localhost:18801
┌─────────────────────────────────────────────────────┐

└─────────────────────────────────────────────────────┘

第 2 步: 输入目标 → 按「开始调查」
  ┌─ 输入: https://example.com

第 3 步: 等待 3-5 秒 → 看到调查方案
  ┌─────────────────────────────────────────────────────┐

  │                                                     │
  │  example.com — 4 IPs, Cloudflare CDN, TLS v1.3      │
  │  ⚠️ 目标使用了 Cloudflare CDN，可能包含 WAF 防护    │
  └─────────────────────────────────────────────────────┘

第 4 步: 访问目标 → DataProbe 自动捕获
  打开浏览器 → 访问 https://example.com
  在目标网站上操作几步（登录、浏览、下单等）
  DataProbe 在后台捕获所有解密后的流量

第 5 步: 查看提取结果（实时更新，每 3 秒刷新）
  ┌─────────────────────────────────────────────────────┐
  │  📦 提取结果                                        │
  │                                                     │
  │  🔑 Token (3)                                       │
  │  ├─ eyJhbGciOiJIUzI1NiJ9...           [📋 复制]    │

  │  └─ Bearer token...                    [📋 复制]    │
  │                                                     │
  │  📡 API 端点 (12) — 启发式自动发现                   │
  │  ├─ https://api.example.com/v1/users                │
  │  ├─ https://api.example.com/v1/products              │
  │  └─ ...                                             │
  │                                                     │
  │  💳 支付数据 (2)                                    │
  │  ├─ weixin://pay?token=...            [📋 复制]     │
  │  └─ alipay://...                       [📋 复制]     │
  └─────────────────────────────────────────────────────┘

第 6 步: 点击任意结果查看详情 → 复制使用
  点击任意证据 → 展开上下文
  → 查看原始请求/响应
  → [📋 复制] → 粘贴到别处使用

第 7 步: 停止调查
  按 [■ 停止] → 调查完成
```

### 3.2 调查模式选择

```
┌─ 模式 A: 快速侦察 ─────────────────────────────────────────┐
│  输入目标 → 按开始 → 看 ADE 方案 → 操作目标 → 看结果        │
│  适用于: 浏览器访问的网站、已知 API                              │
└─────────────────────────────────────────────────────────────┘

┌─ 模式 B: App 分析 ─────────────────────────────────────────┐
│  输入包名 → 上传 APK 文件到引擎 → 按开始                       │
│  → RE 引擎自动分析 APK → 提取 API 端点 + 证书锁定信息           │
│  → ADE 自动配置最优方案 → 开始捕获                             │
│  适用于: 需要反编译的移动 App                                   │
└─────────────────────────────────────────────────────────────┘

┌─ 模式 C: 深度攻克 ─────────────────────────────────────────┐
│  遇到证书锁定或自定义加密的 App:                                │
│  DataProbe 自动检测 → Frida Hook SSL 层 → 在加密前取明文       │
│  如果还有应用层加密 → 需要写一个解密插件                        │
│  适用于: 有锁定/有加密的强保护目标                               │
└─────────────────────────────────────────────────────────────┘
```

## 5. 支持的场景

### 5.1 按目标类型

```
目标类型             能否    推荐通道             需要条件
────────────────────────────────────────────────────────────
网站 (浏览器)         ✅    系统代理 + TLS MITM   无
网站 (API)           ✅    系统代理 + TLS MITM   无
Electron 应用        ✅    系统代理 + TLS MITM   无
原生 Windows App    ⚠️    需要 Frida/管理员     需要 Frida/管理员
移动 App (模拟器)    ⚠️    系统代理             模拟器
移动 App (真机)     ❌     —                   需移动端 Agent
PC 端游 (无锁)       ✅    WinDivert + TLS     管理员权限
PC 端游 (有锁)       ✅    Frida Hook           需要 Frida
PC 端游 (有反作弊)   ⚠️    仅被动分析           不解密，仅元数据
微信小程序          ⚠️    DNS 劫持 + TLS      走系统 DNS 解析的
```

### 5.2 按数据类型

```
数据类型             能否提取    提取方式
────────────────────────────────────────────────────────────
Token / JWT         ✅        规则引擎 + 启发式
支付链接             ✅        规则引擎（全位置扫描）
订单号 / 交易 ID     ✅        规则引擎
用户信息             ✅        规则引擎 + 启发式
API 端点列表         ✅        启发式自动发现
商品数据 / 价格      ✅        规则引擎
装备列表 (游戏)      ✅        HTTP/2 + 规则引擎
加密数据             ⚠️        需写解密插件
WebSocket 消息       ✅        WebSocket 帧解析
二维码支付图片       ✅        提取 Base64
```

### 5.3 按防护强度

```
防护等级          评级    可提取率    需要条件
────────────────────────────────────────────────────────────
无防护             🟢     90-100%    零配置
有 CDN             🟡     80-90%     无
有证书锁定         🟠     60-80%     需要 Frida
有反作弊           🔴     0-20%      仅元数据（不解密）
有自定义加密       🔴     0-80%      需要写解密插件
```

## 6. 理解调查结果

### 6.1 证据详情

点击任意证据行 → 展开详情：

```
┌─ 证据详情 ────────────────────────────────────────────────┐
│  🔑 Token                                                  │
│  value: eyJhbGciOiJIUzI1NiJ9...                           │
│                                                             │
│  位置: step.3.response.body                                 │
│  规则: token_discovery / jwt_token                          │
│  置信度: 90%                                                │
│  来源: TLS MITM 解密后提取                                   │
│  请求: POST https://api.example.com/auth/login              │
│                                                             │
│  [📋 复制值]  [📋 复制 Token]  [🔍 查看原始请求]            │
└─────────────────────────────────────────────────────────────┘
```

**字段说明：**

| 字段 | 含义 |
|------|------|
| value | 提取到的数据值 |
| 位置 | 在哪个步骤、哪个位置找到的 |
| 规则 | 哪条规则匹配到了这个数据 |
| 置信度 | 精确匹配=100%，启发式发现=60-80% |
| 来源 | 数据是怎么拿到的（MITM / Hook / 启发式） |
| 请求 | 这个数据来自哪个 API 请求 |

### 6.2 置信度说明

```
100%  精确匹配（正则/JWT 格式验证通过）
90%   强启发式（结构推断 + 字段名验证）
80%   启发式发现（字段名匹配）
70%   弱启发式（高熵值检测）
60%   不解密分析（大小/时序推断）
```

### 6.3 原始请求/响应查看

在 Pro Mode 中（通过 API 或后续 UI），可以查看:

- 解密后的完整请求 URL
- 请求头（Cookie、Authorization 等）
- 请求体
- 响应头
- 响应体
- WebSocket 消息

```
GET /api/report/json       — 结构化报告（JSON）
GET /api/report/csv        — 表格数据（CSV）
GET /api/report/summary    — 人类可读摘要
```

### 7.3 流量查看

```
GET /api/traffic — Fiddler 风格流量查看器
```

### 7.4 规则管理

```
GET /api/rules              — 列出所有规则
POST /api/rules             — 创建新规则
DELETE /api/rules/{id}      — 删除规则
```

规则 JSON 格式（放在 `platforms/` 目录下自动加载）：

```json
{
  "name": "my_custom_rule",
  "description": "提取我的目标数据",
  "enabled": true,
  "priority": 100,

  "scan_locations": [
    "response.body",
    "request.body",
    "response.headers"
  ],

  "extractors": [
    {
      "name": "my_data",
      "source": "response_body",
      "output_field": "value",
      "data_type": "url",
      "pattern": "\"my_key\"\\s*:\\s*\"([^\"]+)\""
    }
  ]
}
```

### 7.5 插件开发

创建自己的插件放到 `plugins/` 目录，参考 `plugins/example/` 的示例。

## 8. 常见问题

### Q: 需要管理员权限吗？

**不需要，但不是所有功能都能用。** 具体：

```
不需要管理员:  系统代理、TLS MITM、Frida Hook、规则提取
需要管理员:    WinDivert 内核拦截、DNS 劫持、TUN 虚拟网卡、进程注入
```

### Q: 安装 CA 证书有什么用？

CA 证书用于解密 HTTPS 流量。安装一次后：

- 浏览器看的 HTTPS 网站 → DataProbe 可以解密看到内容
- 不装 CA 证书 → 只能看到 SNI（连接了哪个域名），看不到具体数据

### Q: 如何安装 CA 证书？

```
访问 http://localhost:18801/cert → 下载证书文件
双击安装 → 选择"受信任的根证书颁发机构"
```

### Q: 会不会对系统有影响？

```
启动时:  设置系统代理（仅当使用 SystemProxy 通道时）
        不影响其他应用
停止后:  自动恢复原始代理设置
        完全清理，不留痕迹

安全:    所有数据只在本地处理，不上传到任何服务器
        除非你配置了 BackendUrl
```

### Q: 目标有证书锁定怎么办？

DataProbe 会自动检测并切换方案：

```
检测到 OkHttp CertificatePinner → 启动 Frida Hook
检测到 TrustManager  → 启动 Frida Hook
→ 在加密发生前从进程内存中获取明文
→ 不需要安装 CA 证书
→ 前提: 已安装 Frida (pip install frida-tools)
```

### Q: 遇到验证码怎么办？

```
简单数字验证码 → 本地 ddddocr 自动识别（需安装）
reCAPTCHA v2 → 2Captcha API（需配置 Key）
复杂验证码   → 推送到操作员手机，手动输入

三级自动降级: 本地OCR → 远程API → 人工介入
```

### Q: 为什么我什么都没看到？

```
1. 确认浏览器访问的目标和调查目标一致
2. 确认系统代理已设置（SystemProxy 通道启动时自动设置）
3. 检查日志面板（📋 Log）查看引擎运行状态
4. 如果目标是 HTTPS，确认已安装 CA 证书
5. 如果目标有证书锁定，确认已安装 Frida
```

### Q: 数据传到哪里去了？

**所有数据默认只保存在本地内存中**，不上传到任何服务器。如果你配置了 `BackendUrl`，数据会按批次发送到指定后端。后端 URL 默认为空。

## 9. 术语表

| 术语 | 说明 |
|------|------|
| ADE | 对抗决策引擎。自动侦察目标并选择最优攻克方案 |
| 通道 | 数据采集方式：系统代理、内核拦截、DNS 劫持等 |
| 规则 | 定义"提取什么数据"的 JSON 配置 |
| 启发式提取 | 不依赖预设规则，自动发现高价值数据 |
| 证据 | 一条提取到的数据，带来源、位置、置信度 |
| Session | 一次完整调查的全部数据快照 |
| 全位置扫描 | 不只在响应体找数据，在请求体/头/URL/WS 等全位置找 |
| Frida Hook | 通过 Frida 注入目标进程，在加密前获取明文 |
| 不解密提取 | TLS 解不了密时，从包大小、时序、域名中提取情报 |
| JA3 | TLS 客户端指纹。DataProbe 可以伪造任意客户端的 JA3 |
| Plugin | 针对特定目标的定制能力包，丢到 plugins/ 目录自动加载 |
